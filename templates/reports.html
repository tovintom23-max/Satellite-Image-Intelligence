About Generated Reports

Reports are generated from completed analyses stored in the application's analytics history. Each report includes the available results and supporting information for the selected analysis.

Phase 3: RGB Segmentation

Original RGB image, segmentation mask, overlay, image dimensions and class pixel distribution.

Phase 4: Multispectral AI

Spectral bands, raster metadata, vegetation indices and available multispectral classification results.

Phase 5: Object Detection

Available detected-object information, class counts and annotated aerial images.

Model validation notice: The original training class mapping for the Phase 3 RGB segmentation checkpoint has not yet been verified. Category names in RGB segmentation reports should therefore be treated as provisional. Pixel percentages do not represent physical land-area measurements.
